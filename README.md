# 1club team skills

Shared Claude skills for the 1club team.

## Skills

| Skill | What it does |
|---|---|
| [cold-email](cold-email/SKILL.md) | Writes B2B cold emails and follow-up sequences |

## How to install a skill

**Claude Code (desktop app or terminal)**

1. Download this repo (green **Code** button → **Download ZIP**, or `git clone`).
2. Copy the skill folder (e.g. `cold-email`) into `~/.claude/skills/`.
   The result should be `~/.claude/skills/cold-email/SKILL.md`.
3. Restart Claude. Ask it to "write a cold email to…" and it will use the skill.

**claude.ai (web / desktop chat)**

1. Zip the skill folder (right-click `cold-email` → Compress).
2. Go to **Settings → Capabilities → Skills → Upload skill** and pick the zip.
